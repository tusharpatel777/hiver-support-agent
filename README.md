## 🏛️ System Architecture

```text
                      Incoming Customer Tweet
                                │
                                ▼
               ┌─────────────────────────────────┐
               │ [1] Few-Shot Intent Classifier  │
               │   • 8 Bottom-Up Intent Classes  │
               │   • Confidence & Reasoning Out  │
               └────────────────┬────────────────┘
                                │ predicted_intent + confidence
                                ▼
               ┌─────────────────────────────────┐
               │ [2] Intent-Filtered Retriever   │
               │   • Partition by intent first   │
               │   • Top-k Cosine Similarity     │
               └────────────────┬────────────────┘
                                │ (issue, resolution) exemplars + evidence_ids
                                ▼
               ┌─────────────────────────────────┐
               │ [3] Grounded Reply Drafter      │
               │   • AmazonHelp Brand Voice      │
               │   • Actionable Self-Service DM  │
               │   • Evidence Attribution        │
               └────────────────┬────────────────┘
                                │ draft_reply + draft_confidence
                                ▼
               ┌─────────────────────────────────┐
               │ [4] Deterministic Routing Engine│
               │   • Policy sensitive intents    │
               │   • Security/Legal/PII triggers │
               │   • Low confidence guardrails   │
               └────────────────┬────────────────┘
                                │
                                ▼
  Output: {intent, confidence, draft_reply, decision, reason, evidence_ids}
```

## 🎯 Bottom-Up Intent Taxonomy (8 Classes)

Derived from unsupervised K-Means clustering on 5,000 real `@AmazonHelp` customer support threads:
1. `order_status_tracking`: Package transit status, tracking links, dispatch inquiries.
2. `shipping_delay_delivery_issue`: Late shipments, carrier delays, missed delivery guarantees.
3. `refund_and_cancellation`: Order cancellations, refund timelines, return labels.
4. `damaged_or_wrong_item`: Broken, defective, or incorrect products received.
5. `account_access_security` *(Mandatory Escalation)*: 2FA issues, hacked accounts, password reset failure.
6. `billing_and_payment_dispute` *(Mandatory Escalation)*: Double charges, unauthorized card transactions, currency errors.
7. `subscription_and_digital_services`: Prime Video streaming bugs, Kindle Unlimited, digital gift cards.
8. `general_feedback_other`: Service complaints, praise, general company policies.
